[Контекст]
Разрабатывается проект NodeMaster — система управления заметками с перспективой масштабирования в полноценный продукт (API, UI, интеграции).
Текущая итерация — «Ядро»: базовый слой, отвечающий за хранение и управление заметками через JSON.
Ядро проектируется как фундамент, к которому в дальнейшем будут подключаться другие слои (интерфейсы, сервисы, автоматизации).
[Реализация]:
Сгенерируй Python-проект, реализующий модуль «Ядро».
- Создай класс NoteManager, который инкапсулирует всю работу с заметками
- Реализуй методы:
    - create_note
    - get_all_notes
    - get_note_by_id
    - update_note
    - delete_note
- Определи модель Note со следующими полями:
    - id (уникальный идентификатор: UUID или автоинкремент)
    - title (строка, обязательное поле)
    - content (строка)
    - timestamp (строка в ISO формате или datetime)
    - attachments (список строк — локальные пути к файлам)
- Реализуй хранение данных:
    - все заметки сохраняются в файл notes.json
    - если файл отсутствует — он автоматически создаётся
    - формат хранения — список объектов
    - предусмотреть обработку ошибок (битый JSON, отсутствие файла)
- Введи бизнес-правила:
    - нельзя редактировать или удалять заметки, если список пуст
    - редактирование происходит только после получения заметки по id
    - обновление частичное (изменяются только переданные поля)
    - title не может быть пустым
    - attachments должны быть списком строк
- Добавь слой работы с файлами (driver):
    - отдельный модуль file_driver
    - функции загрузки и сохранения JSON
    - абстракция доступа к файловой системе
