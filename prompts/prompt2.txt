[Контекст]:
Проект NoteMaster развивается по итерационной модели.
Первая итерация («Ядро») уже реализована и предоставляет layer для работы с заметками через JSON.
Текущая итерация — «CLI»: создание интерактивного интерфейса для работы с системой через терминал.

Цель — превратить ядро в удобный инструмент управления заметками с командной строкой и интерактивным режимом.

[Реализация]:
Сгенерируй Python-модуль CLI, который подключается к существующему core-слою (NoteManager) и реализует полноценное взаимодействие через терминал.
- Используй argparse для обработки команд
- Реализуй команды:
  - add — создание заметки
  - list — вывод всех заметок
  - delete — удаление заметки по id
  - edit — редактирование заметки по id
- Для каждой команды:
  - валидируй входные данные
  - обрабатывай ошибки (например, id не найден)
  - выводи понятный результат пользователю
- Добавь отдельную команду:
  - --ui — запуск интерактивного режима
- В интерактивном режиме:
  - реализуй цикл (while True)
  - пользователь вводит команды вручную
  - поддерживаются те же команды: add, list, delete, edit
  - добавь команду exit для выхода
  - добавь help для отображения доступных команд

- Интерфейс:
  - красиво оформляй вывод в терминале
  - отображай список заметок в структурированном виде:
    - id
    - title
    - timestamp
    - attachments
  - используй выравнивание, отступы, разделители
- Цвета:
  - ошибки должны отображаться красным цветом
  - успешные операции — зелёным
  - предупреждения — жёлтым
  - можно использовать библиотеку colorama
- Обработка сценариев:
  - если заметок нет — выводить понятное сообщение
  - если файл отсутствует — не падать, а создавать
  - если введён некорректный id — показать ошибку
  - если поля пустые — запрашивать повторный ввод (в UI режиме)

- Расширение структуры проекта:
app/
  cli.py (основная точка CLI)
  ui.py (интерактивный режим)

- Интеграция:
  - CLI должен использовать NoteManager из core
  - никакой прямой работы с JSON

- Логирование:
  - логировать пользовательские действия (add, delete, edit)

- UX:
  - минимизировать ввод пользователя (подсказки)
  - подтверждение перед удалением
  - при редактировании показывать старые значения

[Вход]:
Аргументы командной строки (argparse) или ввод пользователя (в UI режиме)

[Выход]:
Рабочий CLI-интерфейс
Поддержка команд add, list, delete, edit
Интерактивный режим /ui
Цветной и структурированный вывод
Корректная обработка всех ошибок

[Ограничения]:
Без избыточных зависимостей (разрешена только colorama)
Чистая архитектура (CLI не содержит бизнес-логики)
Код должен быть расширяемым
Ошибки не должны приводить к падению программы
