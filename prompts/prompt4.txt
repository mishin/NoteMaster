Проект NodeMaster развивается по модульной архитектуре.
Ранее реализованы:
    - «Ядро» (core) — NoteManager с JSON-хранилищем
    - «CLI» — интерфейс командной строки
Текущая итерация — «Web».
Цель — добавить веб-интерфейс на Flask, который использует существующее ядро без дублирования логики.
Приложение однопользовательское, авторизация не требуется.
Веб-слой должен стать визуальным интерфейсом над NoteManager.
[Реализация]:
- Сгенерируй модуль веб-приложения на Flask, который подключается к core.NoteManager и реализует все операции через HTTP и UI.
- Используй Flask как backend
- Все операции (add, list, delete, edit) должны вызывать методы NoteManager
- Никакой прямой работы с JSON — только через core
- Реализуй маршруты:
    - GET / — главная страница (список заметок)
    - GET /note/ — просмотр заметки
    - POST /add — создание заметки
    - POST /edit/ — редактирование
    - POST /delete/ — удаление
- Добавь обработку ошибок:
    - если id не найден — вернуть сообщение и показать пользователю
    - ошибки отображать в UI (не просто текстом)
